## Getting Started

Clone the repository and install its dependencies:

```bash
git clone https://github.com/thefaraazansari/readme-generator.git
cd readme-generator
npm install
```

## Usage

| Command | What it runs |
| --- | --- |
| `npm run dev` | `vite` |
| `npm run build` | `tsc -b && vite build` |
| `npm run preview` | `vite preview` |
| `npm run lint` | `eslint .` |
